# Managing CDN Migration and Content Relinking

**Role:** IT Manager  
**Area:** CDN Operations · Content Migration · Platform Maintenance

## Situation

As the company expanded, a new CDN server was required.

The hosting provider installed the new server.

## My role

After installation, I:

- created the required folder structure;
- backed up content from the existing server;
- uploaded content to the new server;
- managed the migration over several days because of the size of the media files; and
- updated video URLs on the website where links changed because of the server migration.

## Outcome

After the migration and URL updates were completed, the affected content was accessible without the previous issues.

## What this demonstrates

- CDN/content operations
- Media-file management
- Migration coordination
- Backup awareness
- Website content maintenance
- Operational follow-through
