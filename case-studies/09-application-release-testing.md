# Coordinating Application Releases and User Acceptance Testing

**Role:** IT Manager  
**Area:** Application Operations · UAT · Vendor Coordination

## Situation

The company's website and mobile applications were developed and maintained by an outsourced application-development team.

New updates and features required testing before being accepted.

## My role

After updates were delivered, I oversaw testing of the website and mobile applications.

When a new feature was introduced, I communicated the change to the customer-support team and asked them to test the feature from a user/support perspective.

Their experiences and issues were documented and passed through me to the application-development team where necessary.

I also helped the support team understand how new features worked before the information was passed back to the developers or used operationally.

## Outcome

This created a feedback loop between:

**Development → IT/Operations → Customer Support → Users → Development**

It helped ensure that new functionality was tested from both a technology and customer-support perspective.

## What this demonstrates

- User acceptance testing
- Release coordination
- Vendor management
- Cross-functional communication
- Requirements/feedback management
