# Resolving Website Video Buffering Through Server Load Optimisation

**Role:** IT Manager  
**Area:** Hosting Operations · Incident Coordination · Cost Control

## Situation

Customers began reporting that some videos were buffering on the website while the same content played correctly on the Android and iOS applications.

The issue was investigated and attributed to depleted monthly server bandwidth on the server hosting the website videos.

## Options considered

The company could either:

1. upgrade to a higher server tier; or
2. find a way to reduce the load while managing the remaining period before renewal.

## Action taken

The hosting/server company installed **LiteSpeed Web Server (LSWS)** to assist with caching and reducing workload on the server.

Following the change, video playback improved and customers were able to watch the affected content again.

## Operational outcome

The support team reported a significant reduction in customer calls and chats relating to the buffering problem.

The intervention also avoided the immediate need for a more expensive server upgrade. My work notes estimate that the alternative could have increased server cost by approximately 66.67%.

## My role

I coordinated the issue between the support team, management and the hosting provider and followed the resolution through to the point where the platform was working normally again.
